# Titanic-Survival-prediction-Analysis
Introduction
In this project I will be using the Titanic Dataset which is most iconic and beginner 
friendly dataset available in kaggle to build train and test classification models in 
an data analyst approach, I aim to predict the survival of passengers on the RMS 
Titanic(Royal Mail Ship — a title given to ships that carried mail for the British 
Royal Mail.) using Supervised machine learning algorithms
This Dataset is partially Real and partially re-constructed ,the names, age, gender, 
ticket class, and survival status are historically accurate for many passengers.
However, this dataset is a simplified version created by researchers and 
Kaggle for educational purposes.
It includes only around 891 passengers from over 2,200 on board, and some 
data was filled in or cleaned up for ease of use.
It's great for learning, but not 100% of the original manifest
